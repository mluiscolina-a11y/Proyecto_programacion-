El presente proyecto muestra un codigo que al ejecutarse en python cumple la función de un programa que ayude a calcular Las inversiones y ganancias de un pequeño emprendimiento, proporcionando al usuario el precio de venta adecuado a cada producto.
El programa te pedirá la inversión que se le hizo a cada producto mas el porcentaje de ganancia deseado, seguido de esto dará como resultado un precio de venta.
Este proceso se realizará de acuerdo a la cantidad de productos que desee vender el usuario, presentando al final la sumatoria total de las inversiones, las ventas y las ganancias.
Este programa ayuda a un usuario a sacar las cuentas de su emprendimiento sin incluir impuestos.
